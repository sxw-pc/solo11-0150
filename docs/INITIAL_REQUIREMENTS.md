# 初始需求说明

市场报价是可被交易引用的合同证据，因此必须先证实摊位许可覆盖区域、品种和报价日。同摊位同版异价应冻结两份报价，而不是按导入顺序选择。抽检只对产地、品种和采收日一致的货批赋级；迟到复检按采样时间更新当前等级，但已经结算的交易留历史争议，未结交易停止占用当前等级的可售量。

成交要求买卖双方分别签认同一货批、数量、价格和日期；报价价款、品种与等级必须相容。货批确认占额不能超过可售量，取消回执释放占额，重复取消不二次释放。行情只用当前确认成交，按独立摊位数判断发布门槛；按等级分别建立价格区间，任何上游变化都需可追溯地撤回旧版并重发或标样本不足。

验收证据为 `fixtures/` 中的正常与失败输入、`tests/test_business.py` 的 14 个端到端测试以及 SQLite 内的来源、决策、余额和发布回执。测试打印模块路径，确认运行本仓源码。所有读取和写入均为本地、确定性和可重试。
