# 初始需求说明

市场报价是可被交易引用的合同证据，因此必须先证实摊位许可覆盖区域、品种和报价日。同摊位同版异价应冻结两份报价，而不是按导入顺序选择。抽检只对产地、品种和采收日一致的货批赋级；迟到复检按采样时间更新当前等级，但已经结算的交易留历史争议，未结交易停止占用当前等级的可售量。

成交要求买卖双方分别签认同一货批、数量、价格和日期；报价价款、品种与等级必须相容。旧单次直销输入的货批确认占额不能超过可售量，取消回执释放占额，重复取消不二次释放。

## 交接与转手

同一货批可在摊位间转手并拆分。每张转手回执是双边签认，带摘要、货批、数量、价格、交接时刻、精确的一张前手回执和受让方；一次拆分由多张引用同一前手的回执表达，合计不得超过持有人当时余额。签认买方成为下一步可转出持有人。多来源合流若无逐份去向则保持待核，不猜来源。证明原交接未发生的作废证据或迟到更正沿交接链恢复上游余额、撤回失去来源的下游成交，不按录入顺序让同一公斤同时存在于两摊。货批原始数量仍只由 `grade_decision.saleable` 决定；已结算旧交易遇迟到等级争议保留历史占额与争议记录。

## 身份与行情

经营主体、受益所有人、摊位和采购商从带生效期与签认摘要的主体登记采录；身份按交接日有效登记核对，不得凭摊位名称推断独立性。法律交割账确认每一步当时有可证库存、报价和等级资格的真实转手。两份事前签认的行情合同估计对象不同：

- **市场周转行情**：每次真实转售，仅取最终进入外部采购链的数量；一公斤沿链真实买卖两次可贡献两个摊位价格，回流到先前持有人的部分不贡献价格；
- **采购端到手行情**：只取卖给最终独立采购商的最后一笔成交。

有正量合格份额的成交才进入样本；同摊位多笔先按价格中位数取代表价，再对独立摊位取中位数与原有门槛。两份行情不得互相替代，行情排除不得反写成交无效。

## 验收

验收证据为 `fixtures/` 中的正常与失败输入、`tests/test_business.py` 旧的 14 项端到端测试、`tests/test_handover.py` 的转手/拆分/作废/退款/报价冲突/重放测试，以及 SQLite 内的来源、决策、余额、托管和发布回执。十公斤验收示例：甲→乙 10kg@100，乙→丙 5kg@150，乙→丁 5kg@160，丙→甲 5kg@200；法律交割四笔全确认、甲丁各持 5kg，周转行情 130（两摊），采购端样本不足（一摊）。测试打印模块路径，确认运行本仓源码。所有读取和写入均为本地、确定性和可重试。
